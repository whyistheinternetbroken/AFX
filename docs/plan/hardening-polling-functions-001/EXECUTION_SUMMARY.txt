## 💡 Implementation Reference

The retry pattern is **proven and battle-tested** in `_safe_poll()` (lines 17398–17464):

```python
for _attempt in range(2):  # 1 attempt + 1 retry opportunity
    try:
        # Polling logic here
        return success
    except Exception as _e:
        if _attempt == 0:  # First failure → try 3-round retry
            _reconnected = False
            for _r in range(3):
                if _r > 0:
                    print(f"  ⏳ Waiting 60s... (round {_r + 1}/3)")
                    time.sleep(60)
                if _open_cluster_channel():
                    _reconnected = True
                    break
            if not _reconnected:
                pass  # Fall back to main loop timeout
        else:  # Second failure → unrecoverable
            pass
return False
```
